# Image Usage Guide

## ⚠️ IMPORTANT: No AI-Generated Images

This project uses **ONLY royalty-free, human-created images** from approved sources.

### Current Images:
- **All teddy bears, anime illustrations, and birthday graphics**: Pixabay (free for commercial use, no attribution required)
- **Heart GIFs**: Tenor (check Tenor's terms for your use case)

### To Replace Images:
1. **Use approved stock sites**:
   - Unsplash.com (free, check Unsplash License)
   - Pexels.com (free, check Pexels License)
   - Pixabay.com (free, Pixabay License)
   
2. **Or use your own photos**:
   - Place in `public/assets/` folder
   - Reference as `/assets/filename.jpg`

3. **Paid stock** (if budget allows):
   - Adobe Stock, Shutterstock, iStock
   - Download per license terms

### What NOT to Use:
- ❌ AI-generated images (DALL-E, Midjourney, Stable Diffusion) without copyright verification
- ❌ Fan art or copyrighted characters
- ❌ Random images from Google/Pinterest without license check

### Before Publishing:
✅ Verify every image URL's license  
✅ Add attribution if required (e.g., Freepik images)  
✅ Replace demo content with owned/licensed images  

See `IMAGE_LICENSE.md` for full details.
